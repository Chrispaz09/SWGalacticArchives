Welcome to Star Wars Galactic Archives!
Star Wars Galactic Archives - A Blazor Server application built with .NET 8 and Bootstrap Blazor that allows users to search through the https://www.swapi.tech/ API for Vehicles and Planets. 

Blazor offers a clean, responsive, and modern SPA experience with Blazor Server leveraging SignalR. Bootstrap Blazor is a new technology for me but offered unique out of the box components that were more user friendly than basic html or bootstrap. 

Happy Exploring!

FEATURES:
-Search for a specific Star Wars vehicle or planet
-View detailed information about the item
-Responsive UI
-Basic datagrid functionality

Getting Started:
* NET 8 SDK
* Any IDE that runs .NET 8/ Blazor

1.) Clone Repository 
2.) Open project in IDE
3.) Build project
3.) Run on a browser
